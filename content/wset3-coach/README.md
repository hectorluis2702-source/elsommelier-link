# WSET Nivel 3 · Coach de Estudio

Material de estudio de Hector Garcia para el WSET Level 3 Award in Wines.

- `sesiones/`: presentaciones por sesión (.pptx editables)
- `WSET3_Progreso_y_Palabras_Clave.md`: registro de sesiones y lista maestra de palabras clave
- `plantilla/`: scripts que generan cada presentación con el mismo diseño
- `img/`: imágenes ilustrativas (generadas con IA)
